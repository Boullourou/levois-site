# Données et mémoire : une autorité par information

| Emplacement | Autorité | Ce qui y vit | Ce qui ne doit pas y vivre |
|---|---|---|---|
| ChatGPT / Codex | Réflexion temporaire | hypothèses, plans, explications, tâches ponctuelles | vérité client, mots de passe, dossiers réels complets, source durable de décision |
| Obsidian | PMO et mémoire stratégique | décisions, roadmaps, apprentissages, exports Markdown datés | base transactionnelle simultanée des clients et tâches |
| GitHub | Produit | code, migrations, documentation, fixtures anonymes | données clients, accord TIM réel, CSV privé, média source, secret |
| D1 / cockpit | Vérité opérationnelle future | personne/projet, interaction résumée, tâche, critères historisés, TIM minimisé | audio, transcription, pièces contractuelles, secrets |
| Fichiers locaux / CSV | Source temporaire contrôlée | export Yanport, audit de médias, sauvegarde chiffrée hors Git | canon métier durable sans date/provenance |
| Yanport | Source marché | résultats, annonces et filtres de recherche externes | dossier client LEVOIS, historique de décision humain |
| OMEGA | Source SAFTI ponctuelle | formulaire TIM signé et statut administratif si nécessaire | copie systématique de la relation client dans LEVOIS |
| Agentic trace | Journal d’exécution | mission, entrées autorisées, sortie, horodatage, kill switch, décision humaine | vérité métier, copie canonique d’un dossier, automatisation silencieuse |

## Règle anti-duplication

Chaque information possède : une source, un propriétaire, une date, un niveau de certitude et un emplacement d’autorité. Une copie est soit un export daté, soit une vue dérivée clairement identifiable. Elle ne doit jamais être modifiée comme si elle était l’original.

## Flux de mémoire

```text
Source terrain / Yanport / site
        -> validation humaine
        -> D1 cockpit (lorsque GO sécurité)
        -> export Markdown daté vers Obsidian
        -> observation anonymisée LEVOIS Lab
        -> contenu ou mission agentique approuvée
        -> trace d’exécution, sans retour automatique en vérité métier
```

## Conséquence immédiate

Tant que le cockpit réel est NO-GO, aucune source ne doit être présentée comme la vérité opérationnelle complète. Les informations réelles restent dans le support privé contrôlé choisi par Mouaad, avec minimisation ; le passage vers D1 attend les gates Access, D1 dédiée, conservation et effacement.
