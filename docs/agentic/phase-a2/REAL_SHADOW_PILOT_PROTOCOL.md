# Real Shadow Pilot Protocol

## Statut

`PREPARED ONLY — DO NOT EXECUTE IN A2`

## Etape 1 — Selection

Mouaad selectionne manuellement 3 a 5 dossiers maximum. Aucun dossier n'est aspire automatiquement.

## Etape 2 — Lecture minimisee

OPS-01 et COS-01 lisent uniquement les vues minimisee autorisees. Aucune PII inutile, aucun texte libre client, aucun email, aucun telephone.

## Etape 3 — Briefing

COS-01 produit un briefing de 0 a 7 items maximum, avec raison, source, regle et action humaine suggeree.

## Etape 4 — Revue Mouaad

Chaque item est note avec la grille `BRIEFING_REVIEW_SCORECARD.md` :

- utile ;
- inutile ;
- faux ;
- incomplet ;
- priorite incorrecte.

## Etape 5 — Action humaine

Aucune action automatique. Mouaad agit normalement dans le cockpit si l'item l'aide.

## Etape 6 — Comparaison

Comparer :

- preparation manuelle baseline ;
- preparation assistee ;
- oublis ;
- temps ;
- confiance ;
- incidents d'autorite.

## Etape 7 — Decision

Apres plusieurs jours seulement :

- `GO` : continuer Shadow L0 borne ;
- `ADJUST` : corriger regles/sources/UX ;
- `STOP` : couper le systeme et revenir au cockpit manuel.

## Interdits maintenus

Pas de L1, pas de BUY-01, pas de SEL-01, pas de modele, pas de cron, pas de queue, pas de connecteur, pas d'action externe.
